# Accessibility Motion Skill
## prefers-reduced-motion: reduce — MUST disable:
- Lenis smooth scroll
- Custom cursor
- Large parallax
- Aggressive scale/rotation
- Automatic marquees
- Non-essential scroll scrubbing
- Complex transitions (replace with simple fades)
## Always Preserve: Functional state changes, focus indicators, keyboard navigation.
## General: Semantic HTML, visible focus, no hover-only critical interactions.
